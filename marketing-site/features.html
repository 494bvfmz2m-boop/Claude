Everything, in detail

Built for real servers, not demos.

Every feature below is configured from the dashboard — no code, no redeploys, no waiting on us.

Support

Tickets that actually stay organized

Define as many ticket types as your server needs — each with its own category, staff roles, naming pattern, and welcome embed.

  • Panels with a button (single type) or dropdown (several) that users click to open a ticket
  • Opens a private channel, pings the right staff, and posts the welcome embed automatically
  • Claim and Close buttons right on the ticket, with an optional close reason
  • /change moves an open ticket to a different type mid-conversation — renames, re-pings, keeps every message
  • Closing generates a full HTML transcript, posted wherever you pick — turn it off per ticket type for anything sensitive (billing, appeals) while still logging the close itself
  • A dedicated ticket log channel tracks every open, claim, and close
  • Ban someone from opening tickets at all with a dedicated role, without touching their access to the rest of the server
Moderation

A full suite, on Discord or the web

Ban, kick, mute, warn, and purge — as slash commands, or as a form right on the dashboard, for staff who don't have Discord open.

  • Who can use each one is completely managed by the Permissions manager — not by handing out real Discord permissions
  • Target by username or Discord user ID, not just raw IDs
  • /purge 10 deletes the last 10 messages; /purge with no number clears the whole channel, behind a confirm step — and posts a "purge completed" embed anyone in the channel can see
  • Rank rules apply everywhere — you can't punish someone who outranks or matches you, on either side
  • The punished member gets a DM explaining what happened and why; every action — from Discord or the site — lands in one moderation log, filterable by moderator or action type
  • Add or remove a role across a whole page of selected members at once from the dashboard, instead of clicking through them one by one
Incident response

Lock a channel down in one command

/lockdown stops everyone but staff from posting the instant something's going wrong — no clicking through channel permissions by hand.

  • Posts an embed everyone in the channel can see, explaining it's locked
  • /unlockdown lifts it the same way — clearing the block rather than forcing permissions back open, so the channel returns to whatever it inherited before
  • Who can use either command is controlled from the Permissions manager, same as every other mod action — locking and unlocking are separate grants
  • Every lock and unlock is logged like any other moderation action
Chat

Filters you actually control

A banned-word list and a link/invite filter, both managed from the dashboard — no code, no pull requests.

  • Swear filter: whole-word, case-insensitive matching — won't flag a word for containing one as a substring
  • Link filter: block just Discord invite links (stop server advertising) or block all links entirely
  • Both come with starter templates you can load and edit instead of writing a list from scratch
  • Deletes the message, posts a self-deleting notice, and logs it — staff with Manage Messages are never filtered
  • Both lists are cached in memory, not re-read from the database on every message — busy servers don't add real load
Automation

Auto-punishments that enforce themselves

Set thresholds once and stop tracking warning counts by hand.

  • "At 3 warnings → mute", "At 5 → kick", "At 7 → ban" — however you want it staged
  • Fires the instant a warning crosses the count, no matter which side gave it
  • Logged just like any other moderation action, so there's always a paper trail
Onboarding

A proper welcome, without lifting a finger

Set a channel and a message once — XyphrosMod handles every join and leave from there.

  • {user}, {username}, {server}, and {membercount} placeholders fill in automatically
  • Optionally hands new members a role the instant they join, no bot commands needed
  • Leave messages can post to a different channel than welcomes
  • Uses the same member-list access already granted for the staff list — nothing new to authorize
Staff structure

A real chain of command

/promote and /demote, backed by an ordered rank list you control.

  • You can only act on someone strictly below your own rank — never a peer, never a superior
  • Server owners and Administrators bypass the rule; everyone else plays by it
  • Reorder ranks by typing numbers on the dashboard and hitting save — no more clicking arrows one at a time
  • Demoting the lowest rank removes the staff role entirely
Visibility

A staff list that keeps itself current

One message, always up to date, in a channel you pick.

  • One role per row, with everyone in it actually @mentioned — not just named
  • Pick the embed color to match your server's branding
  • Updates automatically a few seconds after anyone's staff role changes, batched so a bulk update doesn't spam edits
  • Or hit "Post / refresh now" to push it on demand
Content

An embed builder with a real preview

Build any embed — title, description, color, author, thumbnail, image, footer, fields — and see exactly what it'll look like before you send it.

  • Role and user mention pickers drop a real, working mention into the description or a field — no manual ID typing
  • Pick a date and time and it inserts Discord's own dynamic timestamp — "event at 5pm" shows correctly converted to every viewer's own timezone, automatically
  • Starter templates to build from instead of a blank embed
  • Save it as a reusable template, or fire it at a channel immediately
  • The same builder — mentions, timestamps, and all — powers ticket welcome embeds and panel embeds too
Engagement

Reaction roles, built and posted from the dashboard

Map any emoji — unicode or a custom server emoji — to a role, and post the panel to a channel.

  • React to get the role, remove the reaction to lose it — handled automatically
  • Edit and re-post an existing panel and it updates the live message and re-syncs the reactions to match
  • As many emoji → role mappings per panel as you need
  • Mark a panel exclusive to make it single-pick — choosing a new role in the group automatically drops whichever one you had
Community

Giveaways and events, built in

Neither one needs a code channel or a spreadsheet — both live as a single message with buttons, tracked and closed out automatically.

  • /giveaway start takes a prize, a duration, a winner count, and an optional required role — anyone can enter with one click, no reactions to fumble
  • Reroll or end a giveaway early from Discord; a dashboard page lists every one for visibility and cleanup
  • /event posts a title, time, and description with Going / Maybe / Not going buttons and a live attendee count on the message itself
  • Both auto-close and pick winners (or just tally RSVPs) even if the bot restarts in between
Access control

A verification gate before anyone sees the rest of the server

One button, one role, no captcha or bot-guessing games — pair it with Discord's own channel permissions to keep everything else hidden until someone clicks through.

  • Post a Verify button to any channel, with your own message text
  • Clicking it grants the role you picked — instantly, no waiting on staff
  • Enable, disable, or re-post the panel any time from Settings; re-posting edits the same message in place
Communication

Tags and scheduled announcements

Say the same thing without retyping it, and say it at the right time without being awake for it.

  • /tag get <name> posts a canned response instantly — autocomplete finds it as you type
  • Create and delete tags from Discord (Manage Messages) or the dashboard — either way, everyone sees the same list
  • Schedule an announcement once, or set it to repeat daily or weekly, straight from the dashboard — no need to be online when it fires
  • Every deleted or edited message gets logged with the before/after content, in a channel you pick
Permissions

A real permissions manager, not just Manage Server

Everyone logs into the dashboard with their own Discord account — and what they can do there is entirely up to you.

  • Every role on the server is listed, collapsed by default — click one to expand it and see (and change) exactly what it can do, with an at-a-glance badge for how many pages and commands it already has
  • Grant a role access to specific dashboard sections (tickets, embeds, reaction roles, moderation, settings) without giving it any real Discord permission
  • Grant a role specific moderation commands, one at a time — a helper can /mute without being able to /ban; a moderator can /ban without /unban
  • The owner and real Administrators always have full access; the Permissions page itself can't be handed off, so a granted role can never expand its own access
  • You only ever see and manage servers you're the owner of, have Manage Server on, or have been granted access to — never anyone else's
  • Currently in closed, invite-controlled beta — see the front page for availability

Note: XyphrosMod's role needs to sit above the roles you want it to manage in Server Settings → Roles — otherwise ticket access, staff ranks, mutes, and reaction roles won't work for those roles.

Getting started

Never wonder what's left to configure

A checklist on the Tickets page tracks the basics, and disappears once everything's done.

  • Tracks a ticket type, a deployed panel, a mod log channel, and a staff hierarchy
  • Nothing here is enforced — it's a pointer, not a gate
  • Starter templates fill in ticket types (Support, Bug Report, Billing, Appeal), swear-filter word lists, and link-filter presets
  • Every template just loads into the form for editing — nothing saves until you hit Save
Utility

25+ everyday commands, not just moderation

The stuff every server actually reaches for a dozen times a day — none of it needs the dashboard open.

  • Away status: /afk [message] marks you away and renames you — pinging you gets an instant reply, and it clears itself the moment you post again; /afklist shows everyone currently away
  • Reminders: /remind set <time> [message] pings you by DM or in-channel later; /remind list and /remind cancel <id> manage what's pending
  • Lookups: /avatar, /userinfo, /serverinfo, /roleinfo, /channelinfo, /emoji, and /membercount for a humans-vs-bots split
  • Messages: /quote reposts any message as a clean embed, /pin pins one by link, and /snipe / /editsnipe recover the last deleted or edited message in a channel — all Manage Messages only
  • Server tools: /nick, /slowmode, /role add/remove, /invite, and /steal to grab an emoji from anywhere straight into your server (checks your remaining slots first — Discord caps every server at 50, more with boosts) — each gated exactly like every other moderation action
  • /timestamp and /ping / /uptime round it out
Extras

The small stuff that adds up

  • /help — a quick reference of just the commands you can actually use, grouped by what they do
  • /poll — a reaction poll with up to 5 options, optionally auto-closing after a set time
  • /info — see exactly what access you (or anyone else) has, plus a check/cross next to every single command
  • /introduction — XyphrosMod introduces itself in-channel: what it does, how to set it up, and who added it
  • Server stats voice channels show a live member, online, or boost count, renamed automatically every few minutes
  • DMs anyone who messages it directly with the invite link, the dashboard, and a quick rundown
